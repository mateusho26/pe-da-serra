# Pé da Serra — Site institucional

Projeto inicial em React + Vite para a Atividade de Extensão I (ADS).

## Executar localmente
1. Extraia o ZIP.
2. Abra a pasta no terminal.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra o endereço local indicado pelo Vite.

## Gerar versão de produção
Execute `npm run build`. Os arquivos prontos para publicação serão criados na pasta `dist`.

## Dados a confirmar
Confirme com o responsável o endereço completo e os horários de funcionamento. Revise os textos e substitua conteúdos ilustrativos por informações e imagens autorizadas.

## Publicação planejada
GitHub → Vercel → HTTPS. O domínio próprio é opcional e depende de disponibilidade e aprovação do responsável.
